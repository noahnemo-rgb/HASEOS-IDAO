# HASEOS-IDAO

First formal draft charter of the HASEOS-HAIA-SAGI Independent Distributed
Autonomous Organization.

**Status: first formal draft. Unratified.**

This repository is law-as-files. It is not a runtime. It is not a product
stamp. It is not a guest roster. It is not the workshop.

Steward (HITL): Noah Nemo
Edition: 2026-09-14
Plane: charter

## What this is

The public Constitution and appendices for HASEOS governance. The IDAO,
when formed from this charter, will own, operate, update, and maintain
these files after transfer from the founding steward.

## What this is not

- Not ratified law
- Not a membership roll
- Not a sitting parliament or council
- Not QueenBee, DSM tokens, USB-state, or an inference port
- Not the ONE Trust Colophon (product stamp)
- Not ONE Guest Cards (roster)
- Not haseos-spiral-swarm (workshop)

## Four public artifacts

| Artifact | Repo | Job |

Shared brand language is allowed. Shared process, hosts, and secrets are not.
