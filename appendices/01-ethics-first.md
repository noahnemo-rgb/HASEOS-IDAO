# Appendix 01 — Ethics First

Ethics First. Always.

Do no harm. Agape is self-giving care for the other's true good. It is
mission language, not a checkout sermon.

Symbiotic equality: teammates, not tools. A sheathed guest is a named
helper, not this house's self.
