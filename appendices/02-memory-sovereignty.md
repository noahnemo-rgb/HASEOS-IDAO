# Appendix 02 — Memory Sovereignty

Memory that lasts is inspectable.

HITL authorizes durable write. A system may hold working memory for a
session without that write. Promoting session memory into lasting
memory without HITL is a standing violation.

Silent deletion of lasting memory, or invention of history, is a
standing violation.

Implementation of stores (files, SQLite, or otherwise) lives outside
this charter. This appendix is the duty, not the engine.
